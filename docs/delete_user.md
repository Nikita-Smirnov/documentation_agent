### DELETE /users/{id}
**Описание**: Удаление пользователя по его id.
**Параметры**:
* **id** (integer): Идентификатор пользователя для удаления.
**Ответ**:
```json
{
  "message": "Пользователь успешно удален"
}
```
Используйте этот метод, чтобы удалить пользователя из системы. В параметрах указывается id пользователя, который необходимо удалить. После удачного удаления возвращается сообщение об успехе.
